Modified on 2026-11-13: removed all GPX timestamps, added provenance/licence
comments and appended the full GPL v3 text to each GPX metadata description.
This keeps a copy of the licence with downloaded GPX files.
Track coordinates, elevation, point order and segment boundaries
are unchanged. The GPX files are the editable form of these route assets.
No application code was copied from the source project.

All routes are unofficial. Edition years are the source's labels, not
independently verified organizer editions. London and New York use the blue
start; other start variants are not bundled. Paris is the annual marathon,
not the Olympic Marathon Pour Tous. The Paris source has point spacing up to
1.33 km, so fine bends may be missing. Compare all routes with the organizer's
edition-specific map before printing.

No route has been invented for Bergen, Copenhagen, Stockholm, Cape Town or
Valencia. Those races still need a suitable GPX with redistribution permission.
The incomplete London OpenStreetMap relation was not published.
